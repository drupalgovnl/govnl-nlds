## Richtlijnen

- Gebruik altijd de `.dictu-page-header` class voor de hoofding.
- Gebruik semantische HTML: `<header>` voor de hoofdcontainer.
- Zorg voor goede focus-states en toetsenbordnavigatie voor alle interactieve
  elementen.
- Plaats geen andere elementen in de page header, zoals projectlogo's of interactie-elementen. Plaats ook geen elementen boven de logobalk, zoals navigatie. Een uitzondering hierop is de Language navigation. Bekijk de [Rijkshuisstijl](https://www.rijkshuisstijl.nl/publiek/modules/product/DigitalStyleGuide/default/index.aspx?ItemId=11969) voor meer informatie.
  - Op lagere resoluties wordt de language navigation verborgen en via alternatieve methoden aangeboden.

## CSS Klassen

- `.dictu-page-header` — hoofdcontainer voor de hoofding
- `.dictu-page-header__wrapper` — interne grid container voor de inhoud
- `.dictu-page-header__wrapper-before` — container voor de content voor het logo
- `.dictu-page-header__wrapper-logo` — container voor het logo en tekst
- `.dictu-page-header__wrapper-after` — container voor de content na het logo
- `.dictu-page-header__logo-link` - link element voor naar de homepagina

## Toegankelijkheid

- Gebruik altijd een `<header>` element voor de hoofdcontainer.
- Voeg een `lang` attribuut toe voor de juiste taal.
- Het logo bevat een `alt` tag met bijvoorbeeld `Logo Rijksoverheid - Ga naar homepagina` voor screenreaders.
  In combinatie met de titel en/of subtitel van het logo krijgt de link een volledige toegankelijke naam.
- Zie
  [WCAG 2.1.3 Info and Relationships](https://www.w3.org/WAI/WCAG21/Understanding/info-and-relationships.html)
  en
  [WCAG 1.1.1 Non-text Content](https://www.w3.org/WAI/WCAG21/Understanding/non-text-content.html).

## Logo Configuratie

Het logo binnen de page-header kan worden geconfigureerd met:

- **Titel**: De hoofdtitel van de organisatie
- **Ondertitel**: De subtitel of afdeling
- **SVG Logo**: Het officiële Rijksoverheid logo

## Responsief Gedrag

De component past zich automatisch aan verschillende schermgroottes aan:

- **Desktop**: Standaard logo centrering
- **Tablet** (max-width: 48em): Aangepaste logo positie
- **Mobiel** (max-width: 20em): Compacte logo weergave

## Styling

De styling wordt verzorgd door de page-header CSS en importeert automatisch de
benodigde child components:

- `.dictu-page-header`
- `.dictu-page-container`
- `.dictu-link`
- `.dictu-logo`

Plus alle gerelateerde klassen van logo en page-container components.

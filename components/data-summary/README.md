## De Data summary component implementeren

Je kunt de CSS zo in je project installeren:

```console
npm install --save-dev @dictu/data-summary
```

Je kunt de CSS uit `node_modules/` importeren:

```html
<link rel="stylesheet" href="node_modules/@dictu/data-summary/dist/index.css" />
```

Als je CSS imports gebruikt vanuit JavaScript:

```javascript
import "@dictu/data-summary/dist/index.css";
```
